# Anthropic Cert

Small Claude API client. Prep for the Anthropic cert.

## Requirements

- node & npm

Install dependencies:

```bash
npm i
```

## Development

Run dev with:

```bash
npm run dev
```

Run a prompt through Claude:

```bash
npm run x -- "Search for TypeScript tool use and summarize the results"
```

When a prompt is not specified, a sample prompt is used.
